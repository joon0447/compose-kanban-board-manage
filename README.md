# 칸반 보드 생성(수정)

## 기능 구현 사항
- [x] Review 상태를 추가한다.
- [x] 수정, 삭제 모달을 추가한다.
- [x] 태스크 카드를 클릭하면 수정, 삭제 모달이 출력된다.
- [ ] 수정 모달을 통해 태스크를 수정 / 삭제를 할 수 있다.
  - To do 상태 태스크는 담당자 미지정이 가능
  - 나머지 상태 태스크는 담당자 지정이 필수
  - To Do, In Progress -> 태스크 삭제 가능
  - Review, Done -> 태스크 삭제 불가능
- [ ] 삭제, 수정 시 스낵바를 출력한다.
- [ ] 태스크 삭제가 불가능할 때 스낵바를 출력한다.
- [ ] 태스크 상태 전이 규칙을 적용한다.
  - To Do → In Progress
  - In Progress → To Do, Review
  - Review → In Progress, Done
  - Done → To Do
- [ ] 태스크 상태 전이가 불가능할 때 스낵바를 출력한다.
- [ ] 담당자를 지정하지 않고 To do → In Progress 전이를 시도할 때 스낵바를 출력한다.
